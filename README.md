Horizonte Viajes

Horizonte Viajes es un sitio web de una agencia de viajes diseñado para explorar destinos turísticos, conocer paquetes de viaje y acceder a opciones de reserva. Su objetivo es ofrecer una experiencia visual atractiva, organizada y sencilla para planificar próximas aventuras.

 Descripción del proyecto

El proyecto presenta una página web de viajes con diferentes secciones para descubrir destinos, conocer la agencia, consultar opciones de reserva y ponerse en contacto.

La página principal incluye una presentación de la agencia, un buscador de viajes, destinos populares y ofertas destacadas.

Características principales
- Página de inicio: presentación de la agencia y acceso a las principales secciones.
- Sección de viajes: página dedicada a explorar los destinos turísticos.
- Reservas: sección para consultar las opciones de reserva de viajes.
- Galería: espacio para mostrar imágenes relacionadas con los destinos.
- Nosotros: información sobre la agencia.
- Contacto: sección para facilitar la comunicación.
- Buscador de viajes: interfaz con filtros por destino, tipo de viaje y presupuesto.
- Diseño visual: estilos personalizados y elementos interactivos mediante JavaScript.
- Tecnologías utilizadas

HTML5: estructura y contenido de las páginas.
CSS3: diseño, estilos y presentación visual.
JavaScript: interactividad y comportamiento dinámico del sitio.
Google Fonts: tipografía Poppins.

Cómo ejecutar el proyecto
Clona el repositorio en tu computadora:
git clone https://github.com/nicop1706/ProyectoGit01.git

Ingresa a la carpeta del proyecto:
cd ProyectoGit01

Abre el archivo index.html en tu navegador web.

También puedes abrir el proyecto con Visual Studio Code y utilizar la extensión Live Server para visualizar los cambios durante el desarrollo.

Requisitos
Un navegador web actualizado.
Git, si deseas clonar el repositorio.
Un editor de código, como Visual Studio Code, para modificar los archivos.
