# Horizonte Viajes

## Descripción del proyecto

Horizonte Viajes es un sitio web desarrollado como parte de una tarea académica grupal. Su objetivo es presentar una agencia de viajes de manera atractiva y organizada, permitiendo a los usuarios explorar destinos turísticos, conocer ofertas y consultar las diferentes secciones del sitio.

El proyecto busca aplicar conocimientos de desarrollo web mediante HTML, CSS y JavaScript, creando una interfaz intuitiva y visualmente agradable.

## Objetivos

- Desarrollar un sitio web para una agencia de viajes.
- Organizar la información en diferentes páginas.
- Aplicar HTML para estructurar el contenido.
- Utilizar CSS para el diseño y la presentación visual.
- Incorporar JavaScript para agregar interactividad.
- Fomentar el trabajo en equipo y la colaboración.

## Funcionalidades y secciones

- **Inicio:** presentación de la agencia y acceso a las secciones principales.
- **Viajes:** sección dedicada a los destinos turísticos.
- **Reservas:** página relacionada con las reservas de viajes.
- **Galería:** presentación visual de imágenes.
- **Nosotros:** información sobre la agencia.
- **Contacto:** sección para facilitar la comunicación.
- **Buscador de viajes:** interfaz para explorar opciones de viaje.
- **Diseño personalizado:** estilos y elementos visuales implementados con CSS.
- **Interactividad:** funcionalidades desarrolladas mediante JavaScript.

## Tecnologías utilizadas

- **HTML5:** estructura de las páginas web.
- **CSS3:** diseño, colores, distribución y estilos.
- **JavaScript:** interactividad y comportamiento dinámico.
- **Google Fonts:** recursos tipográficos para la presentación visual.
- **Git y GitHub:** control de versiones y almacenamiento del código fuente.

## Instalación y ejecución

### Requisitos

- Un navegador web actualizado.
- Git, para clonar el repositorio (opcional).
- Visual Studio Code u otro editor de código (opcional).

### Pasos para ejecutar el proyecto

1. Clonar el repositorio:

   `git clone https://github.com/nicop1706/ProyectoGit01.git`

2. Ingresar a la carpeta del proyecto:

   `cd ProyectoGit01`

3. Abrir la carpeta en Visual Studio Code.
4. Abrir el archivo `index.html` en el navegador. También se puede utilizar la extensión Live Server para facilitar la visualización durante el desarrollo.
